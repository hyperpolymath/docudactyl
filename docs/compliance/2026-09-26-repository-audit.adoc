== Additional fixes

* Chapel installation now downloads the actual Ubuntu 24.04 amd64 release
  package, verifies its published SHA-256, and installs its dependencies.
  The former `linux64-x86_64.tar.gz` asset does not exist in that release.
* HPC smoke uses a generated WAV, exercises shared and broadcast loading,
  and asserts exact success/failure counts from JSON. Removed the runner-icon
  dependency, silent skip, and ineffective stdin-based success check.
* Added a dependency-light standalone Zig gate and fail-closed CI harness tests.
* Dragonfly replies are bounded and frame-aware across partial/coalesced TCP
  reads. Invalid replies disable reuse after protocol errors. Socket timeout
  installation failure rejects the connection; allocation failure closes it.
  This does not establish thread safety or a connect-time deadline.
* Failed batch hashes no longer hex-encode uninitialised stack bytes: failed
  positions return an empty C string; successful positions retain their digest.
* Zero-sized prefetch windows are clamped before modulo arithmetic; queue-full
  prefetch falls back to fadvise.
* Fixed quality percentile intermediate integer overflow and nearest-rank
  indexing, with zero/one/full-buffer regression tests.
* Corrected a speaker-count test to assert six spoken words (2 + 4); production
  word counting was already correct. The assertion is now exact, not loosened.
* GPU state allocation unwinds on text-buffer failure; the unimplemented
  Tesseract probe no longer intentionally leaks a library handle.
* Consolidated conflicting mise files into `mise.toml`, retaining the project
  pins instead of unrelated `latest` runtimes and success-masking aliases.
* Workflow pin checks now fail on mutable action refs even with trailing
  comments; reduced the linter's token to `contents: read`.
* Pinned the Pages generator checkout and disabled credential persistence for it.
* BoJ dispatch is explicit opt-in, requires configured HTTPS/authentication,
  constructs JSON with jq, times out, and propagates HTTP failures. This
  changes the former automatically failing `.local` push integration; server
  configuration remains a maintainer task.
* Replaced generic contribution/agent scaffolding with repository-specific
  instructions and corrected the security policy's end-to-end-encryption claim.

== Immediate remaining risks and owner decisions

. *Do not treat distributed execution as production-certified.* Shared
  statistics, checkpoint sets, prefetch/GPU/ML handles and the Dragonfly
  request stream need explicit task ownership/synchronisation. See the #32
  plan for counterexamples to the earlier invariant claims.
. *Resume is not aggregate-equivalent.* Indices alone do not restore previous
  statistics, and topology changes can hide old checkpoint files. Checkpoint
  writes truncate in place and errors are swallowed by callers.
. *Cache hits need semantic and artifact coherence.* Keys omit stage/output
  configuration and parser version; timings are not deterministic content;
  cache lookup is not a substitute for recreating requested output files.
. *Optional GPU/ONNX implementations contain placeholders.* Library discovery
  is not evidence that an inference backend executes. Performance estimates
  and backend availability must not be advertised as measured capability.
. *Licensing needs owner review.* README mixes MPL and Palimpsest naming and
  points to PMPL text while source headers/local manifest specify MPL-2.0.
  Existing licence files/notices were left untouched in accordance with the
  estate's no-automated-licence-edit rule.
. *Container reproducibility remains unverified.* Builder/runtime images and
  native packages are not fully locked; the Fedora-to-Wolfi dependency seam
  needs an actual Podman build and runtime test, not guessed image digests.
. *RSR metadata/deployment still needs review.* Do not fabricate completion
  percentages, identity deeds, signing keys or externally served `.well-known`
  policies. Older metadata, the licence discrepancy, and release claims
  prevent an honest blanket compliance assertion.
